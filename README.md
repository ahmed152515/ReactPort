# Demicode Website

Futuristic, premium, high-performance one-page software company site built with React + Vite.

## Tech Stack

- React 19 + Vite
- Tailwind CSS v4
- Framer Motion (micro-interactions + section motion)
- GSAP + ScrollTrigger (advanced scroll/parallax animation)

## Experience Highlights

- Dark mode by default (no toggle button)
- Glassmorphism cards and gradient atmosphere
- Animated hero with background glow and motion blocks
- Scroll-triggered fade/slide/scale reveals
- Parallax interactive section
- Custom cursor follow effect (desktop)
- Fully responsive layout for mobile and desktop

## Run Locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite (usually [http://localhost:5173](http://localhost:5173)).

## Build for Production

```bash
npm run build
npm run preview
```

## Deploy on Vercel

1. Push this project to GitHub.
2. Import the repository in Vercel.
3. Framework preset: `Vite` (or auto-detected as static frontend).
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.
